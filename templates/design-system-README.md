# {{PROJECT}} Design System

_Stage 4. Keep this outline. Every value lives in `tokens.json`; this file explains how to use it._

## 1. Character
One idea in 2–4 words. Three words. The "never" list.

## 2. Voice
Summary of `01 Brand/voice.md`.

## 3. Logo
Files (full, monogram, inverted; SVG/PNG/PDF/EPS; favicons 32/180/512). Clear space. Minimum sizes. Don'ts.

## 4. Colour
Proportion: ~60 ground · ~30 ink · ≤10 accent.

| Token | Light | Dark | Role | Contrast |
|---|---|---|---|---|
| ground | | | page background | — |
| surface | | | quiet panels | — |
| ink | | | text, logo | x:1 on ground |
| ink-muted | | | secondary text | ≥4.5:1 |
| line | | | rules (decorative) | — |
| accent | | | one per view: the key thing | ≥3:1 (graphics), ≥4.5:1 (text) |
| on-accent | | | text on accent | ≥4.5:1 |

The accent rule: one accent element per page, slide or screen.

## 5. Typography
One family (or one sans + one mono). Weights and their jobs. Web scale. Print scale (if print). Line length 60–70 characters.

## 6. Grid & space
Spacing scale (e.g. 4, 8, 12, 16, 24, 32, 48, 64, 96, 128). Grids per format: web, social 4:5, A4.

## 7. Graphic device
The one motif, where it comes from in the logo, how often it may appear.

## 8. Imagery
Subjects, colour treatment, what's banned.

## 9. Icons
One line set, one stroke, sizes; function only.

## 10. Components
Each with a one-paragraph rule and a preview. Example: primary button (one per view), key figure, chapter opener, social post.

## 11. Production
Print colour mode and export settings. Where files go. Fonts uploaded to the shared design tool.
